# Developer Portfolio

Personal developer portfolio showcasing my web development projects, technical skills, and services for potential freelance clients.

## Features

- Responsive design for desktop, tablet, and mobile
- About section
- Projects showcase
- Skills section
- Services section
- Contact section
- Links to live demos and GitHub repositories

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```
